# Customer Segmentation Using K-Means Clustering

## Project Overview
This project uses K-Means Clustering, an unsupervised machine learning algorithm, to segment mall customers based on their annual income and spending score.

## Objectives
- Understand customer purchasing behavior.
- Group customers into different segments.
- Identify the optimal number of clusters using the Elbow Method.
- Visualize customer clusters.
- Predict the cluster of a new customer.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset Features
- Customer ID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Elbow Method
5. K-Means Clustering
6. Cluster Visualization
7. Customer Segmentation
8. New Customer Prediction

## Algorithm
K-Means Clustering

## Conclusion
The project groups customers based on their income and spending behavior. These customer segments can help businesses understand their customers and develop suitable marketing strategies.
